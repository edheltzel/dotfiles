# ProxySoul — Yazi flavor

Deep purple with hot pink accents, from [proxySoul's kitty theme](https://github.com/proxysoul/dotfiles/blob/master/kitty/proxysoul-main.conf)
(the terminal match for Empryo's `proxysoul-main`). A hue-for-hue recolor of the Eldritch flavor.

## Palette

| Role       | Hex       | Role       | Hex       |
| ---------- | --------- | ---------- | --------- |
| Background | `#020204` | Foreground | `#e7e7ee` |
| Surface-1  | `#120e22` | Surface-2  | `#241c3d` |
| Comment    | `#8e8ca1` | Border     | `#3d3b50` |
| Blue       | `#00a2ce` | Green      | `#0b8b00` |

| Red        | `#ee0b2a` |            |           |

## Install

Switch the whole machine with the dotfiles theme switcher: `theme proxysoul`.

## Files

- `flavor.toml` — Yazi UI theme. The `[icon]` block follows the terminal's ANSI palette.
- `tmtheme.xml` — code-preview syntax theme (the same ProxySoul tmTheme used by `bat`).
